# Yozi AI

![Yozi AI 吉祥物](src/static/brand/yozi-mascot.webp)

从一个问题开始，在对话中理解、练习和复习。项目沿用 EXAM-MASTER 的 Vue 3 / uni-app、Pinia、TypeScript 后端和 Python 资料工具，渐进改造为通用自适应学习平台。

核心学习工具免费。可使用自己的云端 API、经授权可达的本地模型，或可选的平台模型服务。没有模型时，可以开始有限的离线规则练习，并看到真实的连接入口；不会用演示回复冒充 AI。平台收费保持关闭，价格与周额度未定。

已接入教学后续观察、持续用户教法保护与受阻换法；统计读取实际教学/作答/变式/调度记录，提示后正确不等于掌握。当前完整交付目标仍进行中，真实模型、设备、公共题源与生产恢复分别验收；功能清单和本轮证据见 [11](docs/11-RELEASE-NOTES.md)。

## 开发入口

当前工具链要求 Node >=22.22.3、npm >=10.8.2，使用 package-lock.json；版本以 [package.json](package.json) 为准。

```sh
npm ci
npm run dev:h5
npm test
npm run lint
npm run build:h5
npm run build:mp-weixin
npm run build:app
```

npm ci 可能连接注册表并执行包生命周期，首次安装先核对锁文件。开发环境仅使用隔离数据。后端构建见[部署指南](docs/09-DEPLOYMENT-GUIDE.md)，真实外部请求的权限与预算见[模型、隐私和费用](docs/14-MODEL-PRIVACY-COST.md)。

## 当前用户路径

输入目标 → 对话讲解和练习 → 自动保存有效作答 → 可靠错题与计划、统计同步更新 → 按表现调整方法与复习。也可以粘贴材料，或通过已授权的分段 PDF / 图片解析连接器导入后局部校对。

“记录与隐私”支持导出、校验预览、同账户合并恢复与撤销最近一次写入。恢复重新验证答案权威、重放有效操作；不会从导入文件直接接受统计或模型密钥。

新增明确访客迁移、退出保留分用户记录、同步冲突双方处理和云端副本删除；资料解析与本地文本模型独立连接并有授权/预算。当前是可本地验收的功能候选，完整[功能清单与证据](docs/11-RELEASE-NOTES.md)区分有限可靠能力、隔离路径及真实外部缺口。视觉优化暂缓。

有界长历史支持50条阅读窗口、本机分页、大备份/访客分批校验与取消、固定版本云同步；旧数据与逻辑v1兼容。上限600万逻辑字符/2万操作，设备空间可能更早用尽，不承诺无限归档。真实本机600条消息路径已验证，设备和公开发布仍分别验收。
