# Phase 0A: 百度网盘 API 技术验证报告

> 日期：2026-04-27
> 状态：已完成

## 一、验证目标

验证百度网盘开放平台 API 能否作为考研大师的免费存储/CDN层，实现：

1. 存储原始 PDF 资料
2. 通过 API 读取文件列表
3. 获取下载链接供 AI 管线下载 PDF 进行加工

## 二、API 能力确认

### 可用的核心 API

| API              | 端点                                             | 功能                        |
| ---------------- | ------------------------------------------------ | --------------------------- |
| 获取文件列表     | `GET /rest/2.0/xpan/file?method=list`            | 列出指定目录下文件          |
| 递归获取文件列表 | `GET /rest/2.0/xpan/file?method=listall`         | 递归列出所有文件            |
| 搜索文件         | `GET /rest/2.0/xpan/file?method=search`          | 按关键词搜索                |
| 查询文件信息     | `GET /rest/2.0/xpan/multimedia?method=filemetas` | 获取 dlink 下载地址         |
| 下载             | `GET {dlink}&access_token=xxx`                   | 下载文件（dlink 有效期 8h） |
| 上传             | 预上传 + 分片上传 + 创建文件                     | 上传加工后的 JSON           |
| 获取用户信息     | `GET /rest/2.0/xpan/nas?method=uinfo`            | 验证 SVIP 身份              |

### 群组服务复核（2026-04-28）

百度网盘开放平台文档中存在“网盘特权服务 > 群组服务”，包含：

- 群组关系维护：获取群组列表、查看群组信息、群成员列表、生成/查询盘口令等。
- 群组文件消费：群组文件库列表、群分享详情、分享文件列表、单个分享转存、批量转存、转存状态查询等。

关键约束：

- 群组服务属于特权服务，需要开发者实名认证，并联系百度商务开通特殊权益。
- 未开通前，仍以 `/apps/考研大师/` 应用数据目录作为稳定主链路。
- 仓库实现层面通过 `Source Manifest` 兼容群组服务、应用目录和浏览器导出清单，避免被单一入口锁死。

### 授权机制

- OAuth2.0 授权码模式
- access_token 有效期 30 天，支持 refresh_token 续期
- **关键限制：每个 access_token 绑定一个百度账号**

## 三、关键限制与约束

### 1. 目录沙箱

> 第三方应用只能访问 `/apps/{产品名称}/` 目录

- 我们只能读写 `/apps/考研大师/` 目录
- 用户在网盘 APP 中看到的路径是 `/我的应用数据/考研大师/`
- **结论：符合预期。`baidu-autosave` 需要转存到这个目录**

### 2. 配额限制

| 状态           | 最大用户数    | 接口频率             |
| -------------- | ------------- | -------------------- |
| 未审核（测试） | **10 个用户** | 10 次/小时           |
| 已审核（上线） | 不限制        | 按需分配（白名单制） |

- **测试阶段仅 10 个用户，10 次/小时** — 足够开发验证
- 上线需要提交应用审核

### 3. 下载限制

- dlink 有效期 **8 小时**
- 不允许浏览器直接下载 **>50MB** 文件
- 需要设置 `User-Agent: pan.baidu.com`
- 支持断点续传（Range header）

## 四、架构验证结论

### 原始方案 vs 实际可行方案

**原始方案（产品文档设想）：**

```
闲鱼资源 → baidu-autosave → 网盘 SVIP
                              ↓ (API)
                    AI 管线下载 PDF → 加工为 JSON 闪卡
                              ↓
                    闪卡 JSON 上传 Laf → 用户 APP 加载
```

**验证结论：方案可行，但需要明确两层架构**

```
┌─────────────────── 管理员层（你的百度账号）───────────────────┐
│                                                            │
│  baidu-autosave → /apps/考研大师/raw-pdf/                   │
│                        ↓                                    │
│  AI 管线脚本 (本地运行)                                       │
│    1. OAuth 用你的账号获取 access_token                       │
│    2. 调 API 列出 /apps/考研大师/raw-pdf/ 下的 PDF            │
│    3. 用 dlink 下载 PDF                                      │
│    4. pdf2flashcard-v2.py 加工为 JSON                        │
│    5. JSON 上传到 Laf 数据库 (或直接打包进 APP)                 │
│                                                            │
└────────────────────────────────────────────────────────────┘

┌─────────────────── 用户层（不碰百度 API）──────────────────┐
│                                                          │
│  用户 APP / 小程序                                         │
│    → 从 Laf 加载闪卡索引 JSON（几十 KB）                     │
│    → 本地刷题 + FSRS 复习调度                               │
│    → 进度同步到 Laf                                        │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 关键结论

| 问题                        | 结论                                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------------------ |
| 百度网盘能当用户端 CDN 吗？ | **不能。** 每个用户需要独立 OAuth 授权，且有严格频率限制。百度网盘只作为管理员的存储后端         |
| 用户端数据从哪来？          | 从 **Laf 云数据库** 或 **APP 内置 JSON**。加工后的闪卡很小（每科几十 KB），直接内嵌或从 Laf 拉取 |
| baidu-autosave 可行吗？     | **可行。** 它是独立的 Python 脚本，定时转存到 `/apps/考研大师/` 目录                             |
| API 频率够用吗？            | **够。** 管线是离线批处理，不需要高频。测试阶段 10 次/小时足够                                   |
| 需要应用审核吗？            | **测试阶段不需要。** 10 个用户够管理员自用。正式上线前需要审核                                   |

## 五、下一步行动

1. **注册百度开放平台应用** — 获取 AppKey/AppSecret
2. **实现 OAuth 授权脚本** — `scripts/baidu/auth.py`，获取管理员 access_token

> **优先级判断：** 以上工作属于 Phase 2（AI 加工管线搭建），当前 Phase 1 小程序已完成，
> 但实际的百度 API 脚本编写需要先注册应用获取 AppKey，这是**阻塞项**，需要手动操作。

## 六、风险点

| 风险             | 影响       | 缓解措施                                           |
| ---------------- | ---------- | -------------------------------------------------- |
| 应用审核不通过   | 无法上线   | 测试阶段不影响，管理员自用 10 人够                 |
| API 频率限制太严 | 管线效率低 | 管线本身是离线批处理，可以控制节奏                 |
| 百度网盘政策变更 | 方案失效   | JSON 闪卡可以脱离百度独立分发（内嵌APP或其他存储） |
| SVIP 过期        | 下载限速   | 管线只在加工时下载，频率很低                       |
