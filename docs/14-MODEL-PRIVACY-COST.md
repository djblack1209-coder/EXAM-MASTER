## 接入能力

对话教法恢复、明确恢复自动/继续任务和受限先修小题均为本机/共享reducer操作，不新增模型消费或平台扣量，不扩大共享授权。模型背景只带当前对话教法，停止任务不调用模型；模型不能释放已保存用户选择。诊断小题与原错答关联，私人资料删除级联清理；同步仍须原明确授权，真实供应商及设备结论保持独立。

平台模型、BYOK 云服务和本地/自部署路径分开。配置显示供应商、真实 model ID、连接状态、能力和费用承担方。切换模型不切换学习记录；明确指定模型不静默替代，故障切换不把密钥发给其他供应商。兼容协议不代表所有型号、视觉或工具调用能力都可用。

当前 learning-provider 支持受限文本结构化适配：HTTPS 公网固定解析地址、响应/时间预算、模型 ID 核对和工具结构验证；流式有本机隔离闭环，未通过的供应商/终端和视觉能力明确限制。Gemini 有有限真实 BYOK 证据；Z.ai/智谱既有真实调用出现 429；本地模型真实可达性仍待验收。

本地连接器需要目标白名单、鉴权、来源授权和真实可达验证。云服务器 localhost 不是用户电脑，手机不能假定直连桌面。公网代理继续拒绝内网、环回、元数据和重定向，不为本地模型解除安全边界。用户不授权资料上传时，不自动改用云服务。

本轮 Node local-text-1.0 已实现 H5→127.0.0.1 连接器→固定数值私网模型目标，只有文本能力；鉴权、预算、超时、重复调用和断连已在真实 HTTP 隔离上游验证。当前电脑没有可用 Ollama 推理服务，真实模型推理仍阻塞，未安装/下载模型。health 仅证明连接器，成功 /chat 才标记模型可达。私网服务可能自行转发外部云端，用户须核对实际服务，不能以 localhost 保证全部本地。运行参数见[09A](09A-LAF-BACKEND-DEPLOYMENT.md)。

退出登录保留分用户本机学习记录，清除身份、模型/资料连接及临时令牌；不同账户不能读取这些记录。访客迁移仅在预览确认后发生，原访客副本保留，不自动同步。冲突归档含双方私人事实，仅当前用户查看/导出；本地删除覆盖该归档。

云端学习副本删除入口实际调用鉴权 delete；它保留本机记录，不删除模型保险库、其他设备缓存或运营备份。用户需停止其他设备同步；后续主动同步可能重新上传本机副本。单资料删除经过范围预览确认，清理本机提取、页图、关联题目/变式、关联对话全部正文与作答、复习及原事件；保留计划分母，清理本机恢复/迁移/冲突副本。详情见[05](05-DATABASE-SCHEMAS.md)。客户端随后请求导入时同一授权解析器的 /delete，只有文件标识匹配的真实成功回执才确认原件与磁盘页图已删。失败、取消、正在解析或缺连接时保留不含正文/令牌的待办，允许重试；同目标同原件待办未完成时拒绝重复导入登记，避免新资料受到旧删除请求影响；其他资料可以继续解析和学习。历史资料缺原解析器定位须在原解析器手工清理，不能凭当前连接猜目标。默认临时目录正常退出仍会清理原件。删除墓碑需主动同步才处理当前云端学习状态；其他设备、导出与运营备份范围分别说明。

## 成本与权益

每次真实调用前设置任务次数/时长/上下文/费用预算，幂等预留→执行→结算→释放。成本账记录供应商、真实型号、价格版本、输入/输出/缓存/推理/识别/重试；上游用量不可靠时标估算或待结算，不能按零。

BYOK actualCost=null / costStatus=pending 表示待确认，不是免费；平台 cost.spent=0 仅表示平台未承担费用。账户调用记录默认最多 500，BYOK 次数上限是可配置资源预算，不是会员权益。失败/取消仍记录上游真实成本，不重复返还权益。

价格、订阅周期、周补给、单位、结转、退款和补充用量尚未最终确定。开发配置清晰标注，默认平台 hardLimit=0 / weeklyUnits=0 / 真实收费关闭。订阅周期与周周期分开，服务端回调验签/幂等，沙箱覆盖时区、并发、取消和退款；不信任前端“已支付”。额度不足由用户主动选择模式，不自动收费或把 BYOK 失败转为平台消费。

软件核心免费，错题、统计、自适应工具不绑定平台模型会员。不承诺无限存储/识别/后台计算，也不以供应商采购折扣作为商业可行前提。生产公开规则、渠道资质及收费授权独立验收。

主观维度编辑、已有评估阅读与统计不扣模型额度。实际模型评估仍走指定模型/共享授权/预算；发送完整当前原答和版本化维度，背景12,000字符超限拒绝，不为评分额外静默上传整份资料、账户标识或其他对话。原答引用验证不是答案权威，模型得分始终AI辅助；没有真实模型预算时只报告隔离传输与合同测试。本地文本连接器目前不执行评分工具，不伪装具备这一能力。

原答定位v2与工具成功收据重试均为宿主免费校验，不新增模型调用。位置和附近原文从已经绑定的原答派生，不额外上传其他资料/对话；题目疑义仅共享field/reason/critical/resolved，超限仍在费用预留前拒绝。模型不能选择旧合同降级、提供权威/附近正文或以重复评分制造可靠判分；缺疑义校对时所有维度未定分。原答、引用与附近上下文均属私人学习内容，导出自行保管、资料删除和恢复副本清理沿既有范围。隔离人工意见不代表真实模型推理或供应商质量验收。

## 流式数据与费用

流式使用相同明确模型/供应商/数据授权/服务端密钥/预算，默认用户主动启用；H5已接Reader、微信接原生chunk但真机待验，现有App明确未开放。没有预设自动升级型号或把流式失败变成REST/平台消费。普通连接成功不代表流式通过，当前配置身份及传输各自验收；更换端点、密钥或能力后重新测试。

预览仅临时内存教学message；密钥回显及Unicode转义脱敏，不保存工具参数、答案、内部推理或未完成输出为学习事实。失败/取消/不完整用量不按零成本结算；确认尚未调用（例如无后端传输或DNS安全拒绝）才记录零。完整用量保留，即使内容截断或被业务校验拒绝。取消记录可能先于预留，在途取消不等于供应商没收费；多实例以同一账本校验，查询故障中止新增输出。

读取原已完成结果不产生上游成本或平台扣量；必须核对同账户、绑定、原题/消息及当前意愿，取消、历史导入或隐私删除后不应用旧工具。账本结果属于同账户私人学习内容，查询受鉴权/限流，不向其他供应商或跨账户返回。TLS模拟上游与隔离浏览器通过不等于真实供应商流式完成；本轮未新增真实模型、OCR、支付或生产调用。

云端副本delete现同时清除当前成本账里的私人教学结果缓存；成本/权益事实及模型保险库继续分别保留。有效单资料墓碑同步也保守清除整个账户的旧结果缓存，不删除无关学习事实。已预留旧任务先取消，晚到内容不能回填缓存；旧结果读取/重播返回已删除，不自动重新消费。失败时显示未完成并重试，不能将部分步骤完成称为全部清除。删除前已传输的内容、其他设备和供应商/运营备份不能由此追回；其他设备未停止同步、后续明确新调用或重新上传仍可形成新数据。

## 模型恢复缓存与账单容量

恢复缓存与正式学习记录分开。服务端 `LEARNING_MODEL_RESULT_CACHE` 配置默认24小时、32条、1 MiB总量、128 KiB单结果；允许1分钟至7天、1至100条、最大4 MiB/256 KiB，单条不得超过总量。无效配置在新调用前拒绝；配置是资源边界，不是会员权益。服务端用UTF8字节计量，在预留、结算、结果/用量查询时CAS维护。到期后不可恢复，闲置账户的物理正文按下次访问清理，当前没有后台定时删除保证。缩短配置立即限制旧结果，延长不延长原到期时间。

容量淘汰保留较新的结果，移除正文时记录原因与时间；不删调用标识、原状态、费用/权益或已保存对话。原请求恢复或重发返回410，不能伪造成功空结果或自动再次消费。一次成功结果即使未缓存，当前响应仍可交付，使用方以实际缓存状态判断后续恢复能力。用户隐私删除优先于过期/容量状态，仍沿用已预留请求取消及分步清理合同。

正常上游usage完整保存至4 KiB；异常大/不可序列化结构只保留已知计费数值、原字节数和可取得的SHA256，标记truncated与待复核。摘要不能复原账单，仍需供应商明细核对，不能把丢失字段按零。未适配的字段、异常token类型/数值或音频计费不自动定价；缺可靠价目或用量继续pending。旧已结算事实不因维护篡改金额，旧大usage压缩为上述证据并保留已有结算事实。账户新预留另有7 MiB安全容量门禁，超限前拒绝外部执行，500条调用/归档缺口仍保留，不以清缓存取消幂等保护。

## 私人页图解读的独立授权

页图入口仅当前题目原片段、匹配的提取版本/事件；用户每次明确确认发送整张页图及当前上下文，经应用后端至当前BYOK供应商。整页可能含旁题、手写作答或教师批注；没有裁剪/去元数据保密保证，用户可先在解析器准备较小区域。未授权不上传，不因本地或文本能力不足自动启用云视觉、平台消费或流式。当前客户端仅H5接入；微信/App、本地与平台图像费用仍限制。

每次一张最多512 KiB且受尺寸/像素约束，不接收远程URL，继续固定公网DNS与TLS/无重定向/服务端白名单。原次数、30秒执行、上下文与结果缓存上限仍生效，无自动无限重试。上游图像价格适配没有通过真实验收，调用账以vision-pricing-unverified与pending保存实际usage，不按文本token价格或供应商文本免费预设结算；BYOK平台权益始终0，上游由用户账户承担。读取原结果/本机校对与统计不重新消费。

图片只用于待校对解读：用户手写/批注/参考答案分别标候选，不升级标准答案；不执行assess/plan或自动建题，不产生作答和可靠错题。结果经结构校验后保存在原对话与来源关联，保守记录帮助；后续明确作答继续原判分规则。取消、账户/题目/共享意愿/原提取变化拒绝旧结果；资料/云副本删除继续清理正文与教学缓存。已发往供应商的页图不能因此追回，运营备份/其他设备仍按既有范围处理。

本机TLS模拟上游的成功仅证明接口、安全、账本与页面闭环；真实供应商图像、手写/公式/含图集和费用报告仍待凭据/预算/人工核验，不以合成一像素夹具宣传识别能力。

本地文本外发背景按现有合同投影，移除云端请求绑定及背景owner；当前目标、最近消息、题目/作答和必要摘要仍受共享许可及原容量限制。此项修复同时适用H5与微信，不改变云端隔离/账本绑定。
