# 小程序视觉体验与增长护城河优化报告

> 状态：已执行第二轮代码优化
> 更新日期：2026-04-28
> 关联范围：微信小程序端首页、刷题中心、登录页、个人页、品牌展示、后续产品规划

## 一、当前 UI 水平判断

如果以一名顶级 UI 设计师的标准评估，当前小程序在“可用性”和“基础一致性”上已经达标，但视觉冲击力仍属于 6.5/10 到 7/10 的阶段。

已具备的优点：

- 绿色品牌方向清晰，已经摆脱幼稚吉祥物路线。
- 底部悬浮玻璃导航有记忆点，符合小而美的小程序策略。
- 首页、刷题、我的三页信息结构足够简单，用户不会迷路。
- 刷题流程已经具备加载、开始、答题、反馈的基本闭环。

主要短板：

- 第一屏原先更像普通工具页面，不像一个有强品牌态度的备考产品。
- 页面卡片过于均质，缺少“视觉锚点”和品牌冲击瞬间。
- 首页对用户留下来的理由表达不足：题库资产、复习节奏、知识图谱价值没有在首屏讲清。
- 登录页仍残留旧“吉祥物”叙事和泛化 slogan，缺少可信、克制、强价值的产品承诺。
- 刷题中心原先只是列表页，不像“训练中枢”，对题库、限时、错题、复习的闭环感不够强。

本轮已经落地的修正：

- 首页左上角品牌从“考研大师”改为 `EXAM-MASTER`。
- 首页首屏改为深绿品牌工作台：`PUBLIC COURSE ENGINE`、今日完成率、剩余题数、连续学习和继续刷题入口。
- 刷题页增加 `TRAINING CONTROL` 训练中枢首屏，强调题库加载、限时训练和复习轨迹。
- 个人页改为“学习资产”面板，承接错题、复习间隔、知识图谱的长期价值。
- 登录页从“AI 助力”泛化表达改为“真题训练、错题复习、知识图谱，一条路径完成”，并加入公共课题库、限时刷题、FSRS 复习三项可信标签。
- 清理小程序代码中的“猫头鹰/吉祥物”残留语义，避免新资源仍被旧叙事污染。

第二轮补强：

- 底部悬浮导航从“大面积绿色胶囊”调整为中性玻璃白底，Wise 绿只作为行动与定位点，降低视觉疲劳。
- 首页首屏接入轻量知识神经图谱，用户打开后能直接看到公共课知识节点、掌握率和强弱节点数量。
- 恢复并重做新手引导页：选择考研公共课路径、英语/数学版本、每日训练强度，完成后写入首页与刷题导航使用的配置。
- 刷题中心从单层题库列表升级为“科目 > 版本轨道 > 训练模式 > 题库”的多级导航。
- 未完成答案校验的题库进入“清洗队列”展示，不发布到刷题入口，避免错误答案污染用户复习资产。

## 二、参考 Nanfu 式冲击力后的转译方案

参考 `https://www.nanfu.global/` 这类官网的强视觉体验，不能直接把小程序做成营销站。小程序用户打开后要立刻完成任务，因此应转译为：

- **第一屏强品牌**：不是大段介绍，而是品牌名、训练状态和核心操作同时出现。
- **单一视觉锚点**：每个主 Tab 首屏只有一个核心面板，避免散乱卡片堆砌。
- **强对比材料**：深绿品牌面板 + Wise 绿高亮 + 玻璃浅绿背景，形成金融级成熟感。
- **产品证据前置**：首屏直接展示完成率、题量、连续学习、加载题库数等可量化证据。
- **动效克制**：底部导航保留 Q 弹和悬浮玻璃，页面主体以轻量转场和按压反馈为主，避免小程序性能风险。

后续如果继续接管视觉，我会按以下顺序推进：

1. **首页品牌系统完成度**：增加学习路径时间线、今日风险提示、下一步任务，而不是继续堆卡片。
2. **刷题页沉浸式改造**：把题目卡片做成更强的“训练舱”，加入速度、连击、知识点定位、答题肌肉记忆反馈。
3. **知识神经图谱预览**：先做 2D 可交互网络，再逐步升级 3D，避免一开始为炫技拖垮小程序。
4. **登录/新手引导重做**：用三屏解释“导入资源、清洗成题、点亮知识图谱”，让用户知道为什么要留下。
5. **视觉资产系统化**：PNG 只负责品牌插画和分享图，功能图标逐步迁移到可控矢量/组件系统，降低 AI 图像不确定性。

## 三、从考研学生视角看完整体验

从注册登录开始，用户真正关心的不是“功能多”，而是：

- 我能不能马上刷到靠谱的真题。
- 答完后能不能知道自己到底弱在哪里。
- 错题会不会自动回来，不需要我自己管理。
- 资源是不是干净，不要机构广告、老师名、乱七八糟文件。
- 这个工具是不是会越来越懂我，而不是又一个题库列表。

当前仍可提升的体验点：

- **登录前信任不足**：需要展示“可先体验示例题库”，降低授权前心理成本。
- **题库覆盖感不足**：刷题中心应该从“几张题库卡”升级为“公共课导航体系”，明确英语一、英语二、政治、数学一/二/三。
- **开始刷题前的目标感不足**：用户应能选择“5 分钟速度训练 / 20 题真题 / 今日错题复习 / 薄弱点补强”。
- **答题后反馈还可以更爽**：正确反馈、连击、震动、下一题转场、XP 不应只是装饰，而要帮助形成速度和肌肉记忆。
- **知识定位要可感知**：每道题答完都应能告诉用户属于哪个知识点、哪个模块、当前掌握颜色是什么。

最能让学生留下来的内容：

- 公共课真题覆盖完整且清洗干净。
- 题目、答案、解析与原资料一致，有证据索引可回看。
- 错题和薄弱点自动复现，减少用户整理成本。
- 限时刷题带来的即时反馈和成绩提升感。
- 知识神经图谱让用户“看见自己变强了”。

## 四、从天使投资人视角看护城河

值得深挖的方向：

1. **资源清洗管线**
   - 护城河不是“有资料”，而是能把混乱资料持续清洗成高可信题库。
   - 增量同步、OCR、PDF 切片、题目答案对齐、知识点标注、证据索引是核心生产系统。

2. **知识神经图谱**
   - 这是别人最难抄走的体验。
   - 如果每个用户的学习状态都沉淀到知识点网络中，产品会从题库工具变成“个人备考操作系统”。

3. **自适应刷题引擎**
   - FSRS 解决复习间隔，ELO/IRT 解决题目难度匹配，速度评分解决考试肌肉记忆。
   - 三者结合后，用户体验会明显区别于普通刷题 App。

4. **资源合规与去机构化能力**
   - 不出现机构、老师、广告相关字眼，是法律和产品调性的双重护城河。
   - 后端保留证据索引，前端只展示中性知识体系。

5. **冷启动路径**
   - 先用“公共课真题 + 限时刷题 + 错题复习”形成最低可传播产品。
   - 分享点不是“我用了一个 App”，而是“这套 5 分钟限时训练让我错题变少”。
   - 用户增长入口应聚焦：考研英语阅读、政治选择题、数学高频基础题三个高频痛点。

别人抄不走的体验：

- 用户长期答题形成的个人知识图谱状态。
- 题库清洗后的证据链和质量评分。
- 基于答题速度、正确率、遗忘曲线的个体化训练节奏。
- 大规模资料增量同步和去噪后的题库生产效率。
- 用户在关键冲刺期积累的错题资产和复习计划。

## 六、下一阶段优先级

P0：

- 公共课题库导航从“题库列表”升级为“考试科目 > 试卷类型 > 年份/专题 > 题目”的多级导航。
- 刷题页增加速度评分、限时模式入口、答题后知识点定位。
- 登录页增加“无需登录先体验示例题库”的低门槛入口。

P1：

- 知识神经图谱先做 2D 小程序版本：模块节点、掌握颜色、薄弱链路、答题后点亮。
- 题库清洗流水线加入证据索引、原文页码、题目答案校验状态。
- 分享卡片改为“今日 5 分钟训练成绩”，用于冷启动传播。

P2：

- 3D 知识神经图谱放到 App/H5 或高性能端，小程序仅保留轻量交互视图。
- 用户分层：基础薄弱、冲刺刷题、错题复盘、单科专项。
- 机构资料清洗后的智能组题进入灰度，避免合规风险和质量波动。
