## 朋友试用部署清单（新方向；只准备，不部署）

准入用现有邮箱验证码加服务端白名单，名单条数不得超过人数上限；移出名单会撤销旧令牌的模型访问，短信保持关闭。邀请邮箱、密钥、真实数据库及指标盐不写入源码或前端。上线前须补齐国产模型完整教学链验收、当前大纲正文与真实微信内浏览器验收。

| 方案                          | 客户需准备                                                          | 验收边界                                                                                      |
| ----------------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 试用：Cloudflare Tunnel       | 自有可用主机、受保护后端与 MongoDB、现有邮件服务、Tunnel 及域名配置 | 国内速度不稳定，微信内打开可能受限；不据此证明正式国内可用；本批不安装 Tunnel 或部署          |

服务端明确配置：`LEARNING_FRIEND_TRIAL_ENABLED=true`、`LEARNING_TRIAL_USER_LIMIT`、`LEARNING_TRIAL_EMAILS`（逗号分隔，完整受邀邮箱）；名单占用名额，非法/空配置拒绝试用；并发依赖现有用户邮箱唯一索引与 CAS 预算账。`JWT_SECRET`、`LEARNING_VAULT_KEY`、`SMTP_HOST/PORT/USER/PASS/FROM`、`MONGODB_URI`、`DB_NAME` 沿受保护配置保管，不复制到客户端。

模型配置：`LEARNING_PLATFORM_MODELS` 指定国产模型、完整端点、密钥环境变量名与输出上限（不超过 2000），真实密钥仅在该后端环境变量；`LEARNING_ALLOWED_ORIGINS` 明确供应商。设置 `LEARNING_PLATFORM_CALLS_ENABLED=true`、`LEARNING_USER_DAILY_CALL_LIMIT`（例如 32）、`LEARNING_GLOBAL_DAILY_CALL_LIMIT`（例如 200）、`LEARNING_GLOBAL_DAILY_BUDGET`（美元；仅有效免费型号才可设 0），原账户硬预算继续生效。价格合同过期或费用待结算保持关闭，不自动换模型或付费。

客户端：`VITE_API_BASE_URL` 指向自有后端，`VITE_CDN_URL` 只能指自有静态资源服务；`ALLOWED_ORIGINS` 对应实际网页域名，禁止通配授权。`VITE_ENABLE_MOCK=false`，美国登录与旧学习扩展不启用；`VITE_TRIAL_MONTHLY_PRICE` 配置第七天意愿卡上的参考价，此卡不收费。网页与微信分端选库/条件编译，PDF.js 仅网页按需加载；微信主包 2 MB、媒体 200 KB 门禁继续执行。

前端运行时地址核对：`src/design/future-motion.js` 的 CloudFront 视频/背景已改用随包素材，未使用的 Figma 图片地址已替换；`src/config/index.js` 的 DiceBear/Icons8/QR 服务默认地址已清空（当前无调用者）；`src/pages/login/provider-utils.js` 的境外身份 SDK 仅在冻结的美国配置明确开启时可用，当前构建关闭。字体原已随包，PDF worker 随包；许可链接、教材来源链接和 SVG 命名空间不构成后台资源请求。产品常规路径只连接自有后端，再由后端连接已授权模型。

上线顺序：核验白名单/邮箱唯一索引、私有库备份与可还原基线 → 本地全部检查和秘密检查 → 构建不可变候选与本地资源清单 → 获得真实部署授权 → 受保护原子切换 → 用受邀测试账号验收验证码、建档、次日复习、个人及全局限额、微信可达性；失败沿原回滚入口切回前一候选并核验旧记录。不得以健康页 200 代替业务验收，不改写用户历史或回滚费用事实。

统计：先构建后端，由管理员在数据库所在主机运行 `node scripts/build/trial-metrics.mjs`；使用有效管理员 JWT（`TRIAL_METRICS_ADMIN_JWT`）、现有后端验签环境及独立 `TRIAL_METRICS_SALT`。仅允许本机 MongoDB 地址，读取字段投影及同步时原子生成的统计事实；无对话正文或密钥输出。旧压缩历史若无统计快照，报告覆盖缺口，不算零活动；不自动迁移。第二周分母为已满十四日用户，每周次数为明确完成的日训练；月费用未知项显示待结算，不能填零。学习指标只覆盖用户主动同步的云端事实，仅本机未同步的活动不可观测，不能把它当成未学习；费用账来自服务端调用。

### 微信网页与小程序

1. **微信内网页**：进入持有公众号的微信公众平台，核对账号有网页授权权限，配置正式网页授权域名，按平台验证文件校验域名。当前完整回调示例为 `https://你的Yozi AI域名/oauth/wechat.html`；域名字段和完整 URL 的填法以对应后台要求为准。
2. 前端公众号公开 ID 为 `VITE_WX_GZH_APP_ID`，后端为 `WX_GZH_APPID`、`WX_GZH_SECRET`；当前请求 `snsapi_userinfo`，在微信浏览器验收授权与返回。公众号 AppID 不用小程序 AppID 代替。
3. **微信小程序**：核对小程序 AppID、管理员及隐私说明；客户端 `manifest.json` 的 `mp-weixin.appid` 和公开 `VITE_WX_APP_ID` 对应小程序，后端为 `WX_APPID`、`WX_SECRET`。配置实际 HTTPS request/upload/download 合法域名与资料选择相关隐私说明；游客模拟不验证真实登录、合法域名、隐私弹窗或手机网络。
4. 普通浏览器扫码已在本地接入独立开放平台**网站应用**的 `qrconnect/snsapi_login`；前端公开字段为 `VITE_WX_WEB_APP_ID/VITE_WX_WEB_REDIRECT_URI`，服务端私有字段为 `WX_WEB_APPID/WX_WEB_SECRET`。完整回调同样为 `/oauth/wechat.html`，发起上下文绑定网站模式，不接受回调改模式。缺网站配置拒绝，不借公众号或移动配置；应用申请与审核见[15](15-MANUAL-SETUP-GUIDE.md)。
5. 网站身份第九项约束和桌面短期保留索引已在腾讯私有空主库受保护地接受，前批八项回执保留，实际限定回退与独立后检通过，详见[09A](09A-LAF-BACKEND-DEPLOYMENT.md)。公网尚未切换；工程侧取得实际已审核网站应用后继续配置、发布与业务验收。当前本地产物没有正式 API 配置，不能直接当线上可用包。
