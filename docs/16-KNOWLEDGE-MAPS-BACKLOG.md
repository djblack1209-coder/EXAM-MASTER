# 知识点框架图 / 思维导图 · 候选与选型（2026-10-21）

当前状态：已用零新增依赖的只读 [知识框架页](../src/pages/learning/knowledge.vue) 和 [学习事实投影](../src/services/learning/learning-progress-read-model.js) 呈现 26 个节点、36 条关系，节点可回看已有证据。它不写掌握事实，不能替代 N3 的收据绑定和预测性准确率核对；本轮原生实操确认无证据节点显示「数据不足」。当前顺序以 [13 的 N1–N3](13-DEVELOPMENT-PLAN.md) 为准。

下列 2026-10-21 候选仅保留选型背景，并非当前依赖或新增授权；小程序开发与验收已暂停。现阶段是只读框架和节点详情，不开放自由编辑、图上答题或对用户资料做外部上传。

## 用户需要的形态

1. **考点框架图**：从考试科目 → 章节 → 考点 → 已练/未练/薄弱，节点可点开看证据与原题。
2. **思维导图**：一张图整理一节课/一篇写作的结构（审题 → 段落 → 句式 → 检查项），可折叠。
3. **错因图**：同一薄弱点下的错题聚成一簇，标出“概念混淆/搭配错误/审题偏差”，点开回到原答。
4. **导出**：PNG/SVG 用于打印或分享；默认排除身份、原答与资料正文。

## 开源 / 免费方案调研

| 方案 | 许可 | 能力 | uni-app / 微信约束 | 结论 |
| --- | --- | --- | --- | --- |
| **markmap**（markmap.js.org） | MIT | Markdown → 思维导图，自动布局、折叠、SVG/HTML | 依赖 DOM；H5/桌面可用，小程序不可直接用 | 可作桌面/网页的“导出/编辑”参考，不作运行时依赖 |
| **mind-elixir** | MIT | 交互式思维导图，拖拽、主题、节点编辑 | DOM/Canvas；小程序适配成本高 | 若以后做“自由编辑脑图”，优先评估 |
| **jsMind** | BSD-2 | 经典脑图，布局与折叠 | DOM/Canvas；小程序不确定 | 备选，不优先 |
| **AntV G6** | MIT | 通用图可视化，树/网络布局、交互 | Canvas；H5/桌面强，小程序 canvas 需适配 | 复杂知识网络可评估，体积较大 |
| **Vue Flow** | MIT | Vue 节点编辑器，拖拽连线 | DOM/SVG；H5/桌面 | 适合“手动整理关系”，不适合小程序 |
| **Mermaid** | MIT | 文本 → 流程图/时序/甘特等 | DOM；可服务端渲染 SVG | 服务端出 SVG 的思路可复用 |
| **Excalidraw** | MIT | 手绘白板 | 体积大、交互重 | 不纳入学生端 |
| **d3-hierarchy** | ISC | 树布局算法（tidy tree） | 纯 JS，可共用 | 若自动布局不够，可只引这一小块 |

免费网站可作灵感/手工整理：markmap.js.org、mermaid.live、excalidraw.com；不作为运行时依赖，也不把用户资料上传到这些站点。

## 推荐路线（不重复造轮子）

**第一步（零新增依赖，优先）**：扩展现有 `figure` 数据合同，新增 `figure.type = 'mindmap' | 'knowledge'`，由宿主用“节点 + 父子关系”生成 SVG：
- 复用 3A 的 `learning-figures.js` 与 `muse-figure.vue`；
- 布局用简单的 tidy tree（层序 + 同层均分；节点 ≤ 40、深度 ≤ 5），先不做拖拽；
- 节点状态 `new | practiced | weak | mastered` 用现有语义色；点节点打开现有证据卡；
- 导出 PNG/SVG 复用现有学习图导出。

**第二步（按需）**：若需要自由编辑/折叠/拖拽，再评估 `mind-elixir` 或 `markmap`，只放桌面/网页，小程序保持只读 SVG。

**第三步**：知识网络（多父节点、交叉连接）再评估 G6；先用父子树覆盖 80% 场景。

## 验收

- 20 节点、4 层的考点树在 390px 不溢出；深色/浅色可读；节点文字 ≤ 12 字，超出省略并可展开。
- 点节点显示：考点、已练题数、正确率、最近错因、回到原题；没有证据时显示“暂无记录”，不推断掌握。
- 图只由已保存事实生成；模型可以建议结构，但节点状态不由模型直接写。
- 导出图默认不含身份、原答、资料正文；分享前可预览。
- 微信主包不增加；图组件走现有分包/按需加载。
