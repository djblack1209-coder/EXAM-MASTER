**总监裁定（2026-10-30 起；10-31 按新简报改写的条目已标明）**

1. **底座方式（10-31 改）**：外壳与运作以本机原版 Muse App 为准；Muse 2、ChatGPT2、Claude2、WorkBuddy2 都是半成品，只作参考，与原版不一致时以原版为准。Yozi 保留 uni-app／Tauri／Laf 技术栈，不改写为 React／Go，不运行或改动这些参考项目。UI 先完全复刻、不夹带改良，用户之后再提改动。
2. **导航（10-31 改）**：一级页面按原版 Muse 的 Chat、Search、Ideas、Goals、Library、Feed、Settings；「AI 团队办公室」「常用指令面板」两个自建构件不复刻。旧蓝图第 5.1 节与 A17 映射表作废。
3. **第 6 节等决定事项**：#1 平台参考模型从本机已有免费通道实测可用者中选定，另选异族模型作裁判，型号随结论登记，不启用付费（**2026-11-01 用户更正**：开发通道加 DeepSeek 付费兜底，`5235a4fd`，见开发日志同日条目；免费与兜底样本单列，不算作免费模型的成绩；11-01 Codex 接续时客户另行明确授权：已配置的 DeepSeek 付费通道可用于本轮隔离质量参考和独立评阅，登记实际型号、参数与费用，不据此启用生产平台教学）；#2 调参样本沿用 2013 英语二「慈善义卖邮件」，另封存 2 道未见过的同类题作留出，只验收不调参；#7 知识树展示形态先做只读框架图＋节点详情，思维导图为只读。#3–#6 不影响主线，维持原状。
4. **知识框架方案第 11 节**：#2 同上；#3 用最新一年英语一／英语二大纲；#4 官网不展示误解原话；#5 两卷同时覆盖、大作文放第二批；#1「参与核对」暂不开放收集，个人层探针在本机运行，口径层只用隔离测试账号，上线前再议。
5. **N1「弱模型提示」子项**：按用户 2026-10-30 对 Lazy 定下的同一原则处理：不新增提示文案，只用界面与布局表达；排在 N1 主问题之后，不阻塞 N1。
6. **写作量规（10-22 调研 T2）**：N1 的批改量规须含反表面特征条款（防写长骗分）；已知分数作文的分档一致率作为 N1 第二段验收，样本须来源可合法取得，取不到就登记缺口。10-22 调研的多学科诊断验证（T1）由定版「首发考研英语写作、理科引擎停在接口层」取代，本阶段不做。
7. **N2 队列规则**：今日队列除到期复习外，把批改中仍未解决的错误作为一等队列项（取自 DeepTutor 拆解第 1 条；用户 10-28 存档，Yozi 重启后取出）。拆解另两条（复述门、语料标来源）到 N3 与个人语料库阶段再评。
8. **N3 写作节点**：写作按能力点组织节点，掌握状态用量规等级，不用「答对即掌握」的四态二值（知识图谱调研第 3 节第三档）。
9. **主动建议层与对话外壳（10-31 改）**：Goals、Library 按原版 Muse 运作原理由模型驱动，进入开发；Ideas（知识点拓展流）属后期，现阶段只核对形态、不抢核心工时。WorkBuddy 走查作废。对话节奏按 Claude Code（见 Y-G5），定版「破冰、两轮内问清意图、关键选择做胶囊」照常适用，但不以压低发言换过程展示。供给维持定版第 7 条修正：自带 API 为主流程，平台通道只留开关。

10. **Feed 不做（11-02 用户定）**：Muse 的 Feed 是内容消费流，Yozi 是单会话学习，没有对应产物。不新增只读动态；代码里 `feed` 隐藏槽位保留不动（导航解析器已拒绝 `visible: true`），不计入任何后续工时。
11. **Ideas 维持现状（11-02 用户定）**：只保留每天用学生自带 API 生成 1–3 条建议、仅预填草稿的最小一条；知识点拓展流仍属后期，不扩卡片形态、不做内容流。
12. **外壳先闭环（11-02 用户定）**：Y-G4 的逐页差异清单列为 Codex 当前第一优先——先拿 `tmp/muse-survey.noindex` 的 25 张原版截图逐页出对照表（缺什么、差几像素、文案与交互差异），再按差异分修复批次；修完再谈其他页面，不先做新页面。
13. **Chat 交互组件方向（11-02 用户定）**：目标对齐 GPT-6 的「Intelligent UI／学习模式」——**默认就给足交互式组件**（用户实测：不主动强调时 GPT 极少给组件），用户不满意可用一句指令调整。路线是「模型产组件描述 → 宿主白名单渲染 → 保留现有结构校验」，不放开任意 HTML／JS；默认密度、可调指令词表、组件白名单与 65／120 秒预算的冲突，先在开发样本上验证再定。
