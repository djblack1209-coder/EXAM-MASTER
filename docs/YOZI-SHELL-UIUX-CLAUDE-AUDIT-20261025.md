# Yozi 新外壳设计审计

**最重要结论**
- **骨架可以保留。** 桌面端已经是“窄图标栏 + 居中消息列 + 底部输入”的学习工作台，方向对，不用重做。
- **开始学习的路径还不顺。** 主要有三处：入口重复且没有文字标签；澄清卡的主按钮看起来像不能点；“未连接”只说状态，不告诉学生怎么办。这三处决定学生能不能自然开始，先改。
- **没有 P0。** 真实教学还没验收：测试账号 ID（QA UID）对不上，等待、流式输出和结果都没跑。这属于功能验证缺口，不算进本次设计问题。

依据标注：【见】= 附件里看得到；【报】= 主线报告；【推】= 推断；【未验】= 没有证据。

---

## A 一句话总评

外壳已经是一个连贯的学习工作台：消息列和输入框对齐，助手和用户的气泡分得清，卡片能明确提交。但导航、状态提示和卡片的主次还会让学生犹豫“下一步点哪里”。真实教学功能没有验收，这和外壳好不好是两件事。

## B 主要优点（保留）

|---|---|---|---|

## C 大问题（无 P0，共 6 项）

**C1 P1｜导航入口重复，而且没有文字标签**
- 证据：
  - 【见】图1（03:14）：左栏 7 个图标，底部还有一个 ☰；顶部另有“☰ 会话”；右上的形状图标（△□○）和左栏重复。
  - 【见】图2（02:57）：右上多了一个“‖”按钮，像暂停或分栏，含义不明。
  - 【见】图4（02:43）：窄屏底栏 8 个图标，都没有标签。
  - 置信度：高。
- 影响：学生想找“今天复习什么”“我的句式库”“进度”，只能一个个点着猜。两个 ☰ 的含义不同。窄屏底栏 8 个格子容易点错，加上输入栏，占掉了屏幕底部约六分之一。
- 最小优化：
  - 按现有页面合并成不超过 5 个一级入口，不新增页面。
  - 删掉右上重复的形状图标。“‖”如果没有对应的任务就删掉，有就加上标签。
  - 两个 ☰ 合成一个。
  - 桌面左栏加悬停提示（tooltip）和读屏标签（aria-label）。390px 底栏最多 5 格，每格带两个字的标签。会话页弹出键盘时隐藏底栏。
- 复验：桌面和 390px 各截一张图；每个入口点一次，确认去对了地方；再截一张 390px 键盘弹出时的图。

**C2 P1｜澄清卡主次颠倒，选中状态不清楚**
- 证据：
  - 【见】图2：主按钮“继续”是灰褐色，看起来像不能点；次级的“跳过，直接开始”是蓝字，反而更显眼；选中的“英语二”只是底色和字重略有变化。
  - 【见】图3、图4 没有选中任何选项时，“继续”和图2 已选时外观一样。【推】能点和不能点的状态分不出来。
  - 【见】全界面的强调色是蓝色，灰褐色只在这一处出现。
  - 置信度：主次颠倒高；能否点击的状态中。
- 影响：学生可能点了“跳过”，丢掉本来能保存的档案信息；也可能不确定自己有没有选好。
- 最小优化：
  - “继续”改成唯一强调色的实心按钮，没选时真的禁用。
  - 选中的选项加强调色描边和对勾。
  - “跳过”降成灰色的次级文字。
  - 全局只留一种强调色。卡片的结构和文案都不动。
- 复验：未选、已选、提交中三种状态各截一张，桌面和 390px、深色和浅色各一套。

**C3 P1｜“未连接”只报状态，不给出路**
- 证据：【见】图1：品牌下方居中一个灰色胶囊写着“未连接”，没有原因，也没有按钮；同一屏的输入框已经聚焦，可以打字。置信度：中，因为不知道它指的是网络、登录还是服务。
- 影响：学生写完学习目标才发现发不出去，或者不知道该去登录还是该等。
- 最小优化：
  - 连接正常时不显示。
  - 出问题时移到输入框上沿，写清原因并给一个动作，比如“未登录 · 去登录”“网络断开 · 重试”。
  - 这时点发送，给出同样的提示，不要没有反应。
- 复验：断网和未登录两种状态各截一张，各点一次发送。这样不会发出模型请求。

**C4 P2｜会话中品牌头一直占着顶部，看不出在学什么**
- 证据：【见】图2：进入会话后，顶部仍是小猫加带底板的“Yozi AI”，大约占 100px，第一条消息紧贴在下面，没有会话标题。置信度：布局高，对使用的影响中。
- 影响：窄屏的竖向空间更紧；学生切回某个会话时，看不出这是哪一次训练。
- 最小优化：空白页保留居中的品牌。进入会话后缩成小猫小图标加当前会话标题（用抽屉里已有的标题），去掉名称的底板。
- 复验：空白页和会话页，桌面和 390px，共截 4 张；再往下滚一屏，看顶部和消息会不会重叠。

**C5 P2｜有待回答的卡片时，输入框被锁住**
- 证据：【见】图2、3、4：输入框提示“请先完成上方选择”，发送按钮变暗。【推】输入被禁用。置信度：中。
- 影响：学生想直接打字回答（比如“英语二，先练小作文”）或者改目标，会被拦住，不符合“一个对话窗口主导”。因为已经有“跳过”出口，所以定为 P2。
- 最小优化：输入框保持可用。学生发送文字就当作跳过这张卡，卡片收起并标“已跳过”，文字按普通消息处理。要先确认现有引擎能接住这种情况；接不住就维持现状，放到核心产出那一批再做。
- 复验：在有待答卡片时输入一句话并发送，截图看卡片状态和消息顺序。

**C6 P2｜抽屉细节（只有早图，先复验）**
- 证据：【见】图3（02:43，名称修正前）：
  - 会话行的日期写成“10/24/2026”，是美式格式，下面还单独多出一行“10 / 24”。
  - 搜索框的提示被截断成“搜索题目、原答”。
  - 抽屉里没有收起按钮，打开后“☰ 会话”也不见了。
  - 抽屉里的搜索和左栏的搜索重复。
  - 置信度：低到中，可能已经修好。
- 影响：找回以前的训练时，日期难读、还重复；不清楚怎么关掉抽屉。
- 最小优化：
  - 日期分组标题用“今天 / 昨天 / 10月24日”，每行里不再重复日期。
  - 缩短搜索提示，让它不被截断。
  - 给抽屉一个收起控件，或者让“☰ 会话”留在原位当开关。
  - 搜索只保留一个入口。
- 复验：在当前构建里打开抽屉截图，再把各种关闭方式各试一次：按钮、Esc 键、点空白处、390px 下返回。

## D 最小优化包（一批做完，统一验一次）

**顺序：**
1. C2：卡片主次和统一强调色。改动最小，收益最直接。
2. C1：收敛导航。要先请您定下一级入口名单，这是**待您决定**的事。我的建议【判断】：对话、今日复习、资料、我的积累（句式、搭配、薄弱点）、进度，具体以现有页面为准。
3. C3：把“未连接”改成能操作的提示。
4. C4：会话中缩小品牌头。
5. C6：先在当前构建上复验，还有问题再改。
6. 往后放：C5 解锁输入框，要先确认引擎能不能接住。

**怎么处理：**
- **保留**：三段式骨架、深灰助手气泡、蓝色用户气泡、卡片四件套和预选、抽屉的单行列表、透明小猫。
- **合并**：两个 ☰ 合成一个；两个搜索入口合成一个；强调色只留蓝色。
- **弱化**：“跳过”按钮；输入框的焦点框调细一些（仍要看得见）；会话中的品牌头。
- **删掉**：右上重复的形状图标；名称底板；没有对应功能的“‖”；抽屉里重复的日期。
- **不算外壳问题**：学生已经写了“英语二”，系统还发卡片问一遍。图2 的预选已经缓解了这一点，彻底处理属于澄清逻辑，放到核心产出那一批。
- **先等看到实际画面再定**：E 表里列出的项目，特别是老用户打开 App 时，空白页要不要显示“今天的下一步”。
