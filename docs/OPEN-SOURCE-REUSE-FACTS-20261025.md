# Yozi AI：开源复用高层事实清单

快照：2026-10-25。用途：供 Claude 只读核查主要功能的开源复用；不是选型结论、许可审计、安装或替换授权。

仅包含项目级想法、公开依赖名/版本及现有高层状态。未检查凭据、未知账号学习资料、模型响应正文或私有实现代码。本文件可作评审材料；来源文件名只表示证据出处，不授权读取其他私有源码、日志、配置补证。

## 证据口径

- **已接入**：现有架构说明或已有功能记录明确采用，不等于本轮跟踪了所有库调用。
- **仅列依赖**：清单/锁文件存在，当前指定功能是否调用尚未核实。
- **自研业务编排**：项目规划明确属于自身教学、学习事实与状态流程；不表示基础设施未复用开源。
- **未知/待验**：现有非代码证据不足，或真实流程尚未完成。不能把待实现/未验写成已有。

本轮不启动服务、不发模型请求、不重验功能。版本来自本机文件，不代表上游最新或实际运行服务器安装版本。

## 当前明确边界

新注册停在正常“创建账户→设置密码必填”：普通自动化填框存在，但没有已确认可避免明文进入工具记录的秘密输入通道；未输入密码、未提交注册、未取得新测试身份。此为真实动作阻塞，不是开源依赖缺失的证明。旧账号恢复调查不再进行。

未提交草稿在当前运行状态中暂存，重载清空符合现有设计；没有据此新增持久化或制造缺陷。本轮未确认可独立改动的其他发动机源码问题，也未新增测试、包或研究框架。
