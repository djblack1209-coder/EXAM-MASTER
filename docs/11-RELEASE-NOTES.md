## 本批流式闭环

- 共用原鉴权、SSRF、明确模型、授权和预算预留/结算。预览只在内存；完整UTF8/SSE、型号/结构/业务校验后才执行工具。
- 同用户/请求独立取消、背压和30秒上游预算；数据库取消顺序检查，跨实例可确认。断流不自动重试、换供应商或改为平台消费。确认尚未调用才记零，已产生或不可靠用量保留真实成本/pending。
- 请求意图关联用户消息、题版本和随机binding；重开后可只读原已完成结果，不追加生成/作答/扣量。选择原模型并授权后才应用；学习/题目/隐私变化、取消或导入历史则拒绝旧工具。
- 连接状态按当前端点、型号、能力与密钥身份摘要绑定；普通/流式分别报告。更换配置后旧成功不能冒充现在可用。
- H5使用Reader、微信原生chunk有隔离适配；App新增保护分块源码与宿主/移动SDK内核编译证据，缺完整DCloud装配时安全拒绝，实际设备仍待验。没有新运行依赖、任意代码执行、微服务或插件市场。
