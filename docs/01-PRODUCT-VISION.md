# 产品定义（2026-10-27 定版）

**一句话**：Yozi AI 是中国学生的 AI 学习教练，先从考研英语写作带练开始。

**为谁**：准备考研、英语写作薄弱、不习惯应试套路的大学生。之后扩展到考公、小学至高中。

**解决什么**：通用 AI 能答疑，但学生不会"指挥"它当老师：不会让它逐句带练，不会安排每日训练，第二天它也不记得进度。Yozi 替学生当这个指挥。

**怎么学（考研英语写作）**

1. 对话建档：英语一/二、考试时间、目前水平、每天可用时间；可上传自己的资料。
2. 10 分钟摸底：句子成分、固定搭配、翻译短句、长难句，生成第一份薄弱点图。
3. 每日训练：到期复习 → 固定搭配 → 中译英/英译中短句 → 长难句 → 写作逐段带写 → 小结。
4. 写作逐段带写：审题提取信息 → 确定结构 → 每段固定句式 → 逐句反馈与改写 → 成文；学到的句式进入个人句式库，按遗忘规律复习。
5. 看板：距考试天数、本周学习天数、搭配与句式掌握、薄弱点、写作篇数。

**与免费通用 AI 的区别**：记得进度、主动安排、按时复习、薄弱点可见、句式越积越多；反馈区分 AI 评估与可靠判定。

**端的分工**：桌面端和手机 App 为主线，记录同步；官网是正式一端，负责下载 App、注册登录，以及只读查看本人已同步的学习进度。研发主线只做桌面和手机App；小程序的功能开发、界面适配及构建验证全部暂停，已有代码和构建产物保留不删，仅保留未来辅助定位。品牌采用官网背景原有的黑白扫描线小猫，Mac 图标使用不透明纯白底。

**模型与业务模式**（2026-10-26 更正）：用户注册后接入自己的 API 使用模型，型号实时读取、可接多个、按账号保存；Yozi 的价值在教学方法、每日安排、学习档案与复习，不转售模型。测试版在写作主链质量达标后公开，以小红书营销、先体验产出及反馈换额度引流，随后引导连接或订阅；额度数值按测试期营销需要确定，开发期只预留开关，当前BYOK主流程保持。

**留存与掌握**：卡片／练习留下结构化事件，下一次打开的今日队列必须因此改变。掌握核对看下一道未见过的同节点题的预测表现，绑定平台参考模型；BYOK 另标来源，拍照识别计入完整链路，数据不足显示「数据不足」。知识树 Yozi 独立建设，先一科一学段、节点收据与版本依据，再做可视化。

**验证与获客门槛**：开发侧自验、优秀样本对照和留存环验证照常推进，不设招募用户的人工测试前置。核心产出质量过硬后，再推进习惯养成、公开测试和免费引流；掌握预测数据不足的节点继续显示「数据不足」。

**成功标准**：试用期看四个数：第二周仍在使用的人数、每人每周带练次数、愿意付费的人数、每人每月模型成本。

**推进顺序**：当前工单照常收尾；后续内容质量第一、留存第二、细节第三。讲解、批改、练习分别对标最优秀样本，最低接近、目标超越；WorkBuddy走查作为后续界面改造输入。知识树先数据层后展示层，由Yozi独立建设，账户与数据均不与Lazy共用，也不预留互通。依 [目标定版](../双产品目标形态-定版-2026-10-27.md) 文末总优先级执行；科目仍按考研英语写作 → 申论 → 中小学理科扩展，当前不扩理科引擎。
