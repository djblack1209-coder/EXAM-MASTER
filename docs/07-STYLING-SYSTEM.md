## 2026-11-02 小猫行为与状态机重做方向（客户）

**原则：不做 Logo 微调，做"有生活感的角色表演"。** 小猫是产品人格，不是品牌图标；状态要能被读懂，动作要有停顿和过渡，不能整张图机械循环。

### 状态清单（第一版）

| 状态 | 触发 | 表演 |
|---|---|---|
| 静候（curious） | 打开、空闲 0–3 分钟 | 好奇歪头、偶尔眨眼、尾巴轻摆 |
| 打瞌睡（dozing） | 无操作 ≥ 3 分钟 | 头一点一点、耳朵抖动、被声音惊醒一瞬再眯 |
| 睡着（sleeping） | 无操作 ≥ 10 分钟 | 趴下收爪、呼吸起伏、尾巴慢慢收拢 |
| 被唤醒（waking） | 任意输入／事件 | 伸懒腰、睁眼、甩头，接下一状态 |
| 学习/打字（studying） | 进入练习、带写、批改中 | 面对笔记本两只前爪交替敲击，偶尔抬头看用户 |
| 思考（thinking） | 模型请求中、复核中 | 托腮望上、耳朵前倾、尾巴末端轻点 |
| 等待作答（waiting） | 有题目未作答 | 团坐、慢眨眼、看向输入框方向 |
| 完成（celebrate） | 一轮训练完成 | 伸爪、竖尾、一次性跳起 |
| 出错（error） | 请求失败、校验拒绝 | 压耳、垂尾、收爪，停在原地不循环 |
| 停止（stopped） | 用户停止任务 | 趴下、尾巴盖住爪子 |

- 动作分段：入场 → 循环段 → 退场，循环段至少 2 个错峰小动作，不整段回放。
- 形象仍沿 `src/assets/brand/kitten-icon-master.png` 的辨识特征（圆脸、大眼睛、猫耳、扫描线），但动作与道具（笔记本、坐垫）是新画的，不基于 Logo 变形。
- 素材只做透明背景、不加底板；新增素材须先报客户确认，再进 `src/assets/brand/`。
