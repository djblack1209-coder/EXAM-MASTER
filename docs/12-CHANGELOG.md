## 2026-10-19 · 修复两处回归阻塞

- 跳过建档保留用户已选或目标里已明确的考试类型，不再强制写回英语一；新一轮从种子重来，不继承上一轮选择。
- 资料保存与绑定合并为一个先断言后写入的动作，忙碌时一笔都不写，消除「已保存未绑定」；粘贴入口同款修复，双向竞态用按钮禁用与调用前判定一起堵。
- 新增组件级与 store 级回归测试；缺陷在修复前分别以 `expected 'english1' to be 'english2'` 和 `materialsAdded=1 bound=0 BUSY` 复现。

## 2026-10-19 · 建档改为点选，采集多方向意图

- 入口先选「你在准备什么」（考研英语/政治/数学/专业课、考公申论、四六级、其他），选定方向才允许建档；非考研英语方向交回通用对话，不假装能上课。
- 考试类型、每天时长、考试时间、同时在准备的方向全部改为可点选，只有「还想让我知道什么」保留自由文本；用户不必先想清楚该说什么。
- 档案新增可选的 `subjects`/`track`，旧档案缺少这两个字段时一切照常；跳过早先点选的方向会被保留，不再被清空。
