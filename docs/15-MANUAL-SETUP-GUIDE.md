先办理普通浏览器的微信扫码登录，美国区另需客户提供 Apple/Google 开发者配置，短信通道保持关闭。公众号、小程序优先复用已有账号；移动应用与正式签名按对应端准备进度办理。本指南也附有可直接交给外部助手的提示词，扫码、验证码、证件、协议和付款由你接管。

**当前事实（2026-10-03）**：普通浏览器微信网站登录已完成本地接线、回调保护、相关回归、跨端构建和本机隔离数据库验证；网站应用配置仍缺失，真实扫码没有通过验收。腾讯上一批已接受的是八项身份索引，本批新增网站身份约束尚未迁入服务器。申请通过之后，配置、受保护迁移、发布和真实业务验收仍由工程侧完成。

**判断**：先确定正式网页地址和实际申请主体，能避免审核时反复修改应用与回调。下文的方括号都是待填写内容，不能原样提交。

## 2. 普通浏览器微信扫码：微信开放平台网站应用

入口：[微信开放平台](https://open.weixin.qq.com/)。这里选择**网站应用**，与公众号、小程序、移动应用分别办理。

### 页面 A：登录和主体认证

1. 打开入口，点“登录”；账号登录、扫码或验证码由你接管。如果已有账号，先使用已有账号查看资产。
2. 找“账号中心”中的“开发者资质认证”或当前同类入口，先看认证状态。已认证且主体正确就复用；未认证则读取本页的主体类型与材料要求。
3. 主体名称、证件信息、联系人按真实材料逐项填写。没有该类主体资格时，记录平台提示，不选择不真实的企业或机构身份。
4. 上传证件、管理员验证、签署协议和任何费用由你完成。保存申请编号与状态；不把证件或认证密码交回聊天。

### 页面 B：创建或核对网站应用

1. 找“管理中心”→“网站应用”。先检查是否已经有问理或对应正式域名的网站应用，避免重复申请。
2. 没有时点“创建网站应用”或对应创建入口。有时先选已有应用并查看详情。
3. 按下表填写公开信息，再由你检查主体和域名后提交实际申请。

## 4. 已有公众号与微信小程序：核对归属、域名和权限

入口：[微信公众平台](https://mp.weixin.qq.com/)。先核对登录的是公众号还是小程序，以及主体、管理员、AppID 是否对应本项目已有配置。不要为了修普通浏览器扫码而重复注册这两种应用。

### 公众号内网页登录

1. 登录公众号，找到“公众号管理”→“功能设置”→“网页授权域名”→“设置/修改”。旧界面入口名称可能不同，按实际页面定位“网页授权域名”。
2. 填正式**网页域名**；下载该页校验文件，交工程侧部署到该域名根目录，再回本页验证并保存。该菜单及验证文件流程见[腾讯官方域名指引](https://cloud.tencent.com/document/product/1301/100434)。无需为此购买或接入微搭。
3. 在开发者信息/接口权限页核对公众号 AppID 和网页授权权限。密钥只保存在私有位置。
4. 本项目在微信内请求公众号授权；公众号配置和普通浏览器网站应用配置分别填写。真机在微信内的授权、取消与返回由你配合实际验收。

### 小程序登录、网络与隐私

1. 登录已有小程序，在“开发”→“开发管理”→“开发设置”核对 AppID。
2. 找“服务器域名”→“修改/开始配置”，由你完成管理员扫码。request 填实际 HTTPS 后端来源；上传/下载填本产品实际使用的对应 HTTPS 来源，由工程侧给出清单。仅填来源，不填某个 `/login` 接口路径。[腾讯官方菜单说明](https://cloud.tencent.com/document/product/1081/47685)。
3. 找“用户隐私保护指引”或当前隐私设置入口，按**实际启用的能力**填写处理目的、范围和联系渠道。资料选择等能力先由工程侧提供当前使用清单；未启用的能力不勾选。
4. 在“成员管理”给实际验收人员对应开发/体验权限；保留现有成员，不扩大为平台管理员。具体成员授权由你确认。
5. 工程侧准备体验版后，在“版本管理”检查体验版，再按实际手机验收。正式提交审核和发布是后续独立步骤。

仓库中的 AppID 或已有环境字段只证明存在配置，不能证明账号属于你、已审核或当前权限可用。开发工具中跳过合法域名/隐私校验也不能作为真机通过。

## 7. Apple 正式签名：需要正式交付时办理

本机模拟与当前未公证的 Mac 包可继续开发；正式签名、公证或商店交付按实际发布安排办理。

1. 打开 [Apple Developer 注册页](https://developer.apple.com/programs/enroll/)，点 **Start your enrollment**；已有有效会员先使用已有团队。
2. 用开启双重认证的 Apple Account 登录。个人填真实法定姓名、邮箱、电话和地址；组织填真实法人实体、授权负责人、D‑U‑N‑S、工作域名邮箱和有效组织网站。账号验证、证件、协议与付款由你完成。官方当前列示会员年费 99 USD，地区价格可能不同，以实际结算页为准；本指南不授权付款。[官方会员要求](https://developer.apple.com/programs/enroll/)。
3. 需要移动 App ID 时，进入 **Account → Certificates, Identifiers & Profiles → Identifiers → + → App IDs → Continue**。Description 可填 Wenli；选 **Explicit**，Bundle ID 必须与实际 Xcode target 相同。检查后点 **Continue → Register**；仅启用实际需要的能力。[官方 App ID 步骤](https://developer.apple.com/help/account/identifiers/register-an-app-id/)。
4. Mac 官网分发用 Developer ID Application 签名，证书申请入口与要求见 [Apple 官方 Developer ID 说明](https://developer.apple.com/help/account/certificates/create-developer-id-certificates/)。工程侧准备 CSR/签名方案，你在自己团队下完成平台身份/权限步骤，私钥留在本机钥匙串或既有私有位置。
5. 回传团队名、Team ID、会员状态与证书所在位置；工程侧继续签名、公证和安装验证。完成会员申请并不自动完成公证或发布。
