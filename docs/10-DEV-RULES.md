# 开发规范

用户授权范围优先。本地可恢复改造持续完成，不把普通工程选择变成问卷；新增费用、生产部署、真实收费或破坏性恢复另需授权。先核实 Git 前态和运行事实，保留用户已有修改，不强制重置。

## 代码

页面/组件 → Store → Service → Backend。新 Vue 使用 Composition API；旧 Options API 渐进维护，不整库风格重写。JS/Vue/TS/脚本用 ESLint / Prettier，Python 用 Ruff 和 4 空格。后端显式 ESM 扩展名，Node16 解析不是 Node16 运行建议。保持公开导出和数据键兼容，短注释说明权限与合同。

删代码先核对静态导入、模板、easycom、pages.json、测试、导出 API 和平台分支。FSRS 子包副本是有意包体边界，审计一致；不因为重复字节就合并到主包。第三方代码/许可不无依据改写。

## 正确性和安全

保留鉴权、授权、限流、输入验证、用户隔离、SSRF、硬预算和幂等。密钥不进入前端、日志、普通备份或提交。模型/材料/工具输入不能改变权限，生成输出验证后才执行；只有成功工具结果才能宣称状态变更。

可靠作答、提示修正、原题重做、变式和复測分别保留；探索、引用和歧义不记错。统计共享事实、显示分母，计划保留版本，来源与答案分开验证。BYOK 不扣平台权益，未知成本待结算，生产价格未定及收费关闭。

## 验收和历史决策

按影响检查并修复本次引入失败；测试、真实依赖、设备和公开发布分别报告。保留 API 模块替代 lafService、离线已知材料可读、统一路由拦截、H5 分包与 gzip 的既有决策。PK/游戏常量只为旧入口兼容，不重新占据主学习流程。

核心文档集中 docs/，职责见 00；临时证据忽略且脱敏。 文档可引用被 Git 忽略的本机证据；仓库审计登记这些链接，不要求干净检出携带证据，也不回写历史证据。非忽略目标、已跟踪文件、源码导入与脚本入口继续严格核对。同步更新对应合同和 12。依赖由锁文件安装，自动更新只产生审查 PR，策略见 08C，不自动跳过门禁合并或上线。

CI 使用的根目录与 standalone 后端锁文件、Python requirements 清单必须跟踪，不得被父目录忽略规则漏掉。干净检出核验分别实际安装依赖；离线缓存缺失时停止并报告，不以符号链接复用依赖或安装失败后的未运行步骤宣称 CI 通过，具体命令见 08C。
